# CS111 Lab 19: recursive functions

1. Clone this repo: `git clone https://github.com/ct5492/fa2026-cs111-lab19-starter.git`
2. Go into the folder: `cd fa2026-cs111-lab19-starter`
3. Open `recursion.cpp` and follow the steps on the Lab 19 page in Brightspace.
4. Compile: `g++ recursion.cpp -o recursion`
5. Run: `./recursion` (on Windows: `recursion.exe`)
6. Submit `recursion.cpp` in Gradescope.
